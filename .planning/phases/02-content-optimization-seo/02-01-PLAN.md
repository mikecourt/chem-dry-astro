# Plan 02-01: Schema Markup & Meta Description Optimization

## Overview

**Phase**: 2 - Content Optimization & SEO
**Plan**: 1 of 2
**Goal**: Enhance schema markup for local SEO and optimize meta descriptions for CTR

**Estimated Duration**: 15-20 minutes
**Risk Level**: Medium (schema changes affect structured data in search)

## Context

### Current State
- SchemaMarkup component exists but is minimal (LocalBusiness + AggregateRating only)
- Missing critical local SEO properties: `areaServed`, `geo`, `address`, `openingHours`
- Meta descriptions exist on all 7 pages but vary in optimization quality
- No canonical URLs set on city pages

### Target State
- Full LocalBusiness schema with all recommended properties per 2025 best practices
- City-specific `areaServed` with proper City/State/PostalCode types
- Optimized meta descriptions with primary keyword, city name, value prop, CTA
- Canonical URLs pointing to production domain

### Research Findings

Based on [Schema.org documentation](https://schema.org/) and [2025 local SEO best practices](https://localmarketingsolutionsllc.com/blog/local-schema-markup-guide/):

1. **areaServed** property is critical for service-area businesses - defines geographic coverage
2. **geo** property with lat/long coordinates essential for "near me" searches
3. Rich snippets with proper schema improve CTR by 20-30%
4. Use specific schema subtypes (HomeAndConstructionBusiness or LocalBusiness)
