# Phase 3 Plan 1: Quote Form Backend & Netlify Integration

## Objective

Create a functional quote form submission system using Netlify Forms, replacing the non-functional `mailto:` pattern and enabling form tracking and lead capture.

## Context

### What Exists
- `src/layouts/partials/CallToAction.astro` - Complete quote form UI with:
  - Name, Email, Phone, Zip Code, Services fields
  - Form action pointing to `/api/contact` (doesn't exist)
  - Validation and styling already implemented
- `src/pages/contact.astro` - Simple form with `mailto:` action
- `src/pages/appointment.astro` - Similar `mailto:` pattern
- `src/config/config.json` - Contains `contact_form_action: "mailto:office@whiteglovecarpet.com"`

### What's Missing
- No functional form submission endpoint
- No Netlify Forms configuration
- No form success/error feedback pages
- No form submission tracking

## Tasks

### Task 1: Configure Netlify Forms
**File**: `src/layouts/partials/CallToAction.astro`
**Action**: Update form to use Netlify Forms pattern

Convert existing form to Netlify-compatible format:
```astro
<form
  name="quote-request"
  method="POST"
  data-netlify="true"
  netlify-honeypot="bot-field"
  action="/thank-you"
>
  <input type="hidden" name="form-name" value="quote-request" />
  <p class="hidden">
    <label>Don't fill this out: <input name="bot-field" /></label>
  </p>
  <!-- Existing form fields remain unchanged -->
</form>
```

**Verification**: Form appears in Netlify dashboard after deploy

### Task 2: Create Thank You Page
**File**: `src/pages/thank-you.astro` (create)
**Action**: Build conversion confirmation page

Include:
- Success message with next steps
- Phone number for immediate contact
- Link back to homepage
- Tracking event trigger (GTM-ready)

Template structure:
```astro
---
import Layout from "@/layouts/Layout.astro";
import CallToAction from "@/layouts/partials/CallToAction.astro";
---
<Layout title="Thank You | Brimley's White Glove Chem-Dry">
  <main class="pt-32 pb-16">
    <div class="container max-w-2xl text-center">
      <h1>Thank You!</h1>
      <p>We've received your quote request...</p>
      <p>Call us now: <a href="tel:4806493663">(480) 649-3663</a></p>
    </div>
  </main>
</Layout>
```

**Verification**: Page accessible at `/thank-you`, displays correctly

### Task 3: Update Contact/Appointment Forms
**Files**:
- `src/pages/contact.astro`
- `src/pages/appointment.astro`
**Action**: Convert from `mailto:` to Netlify Forms

Apply same Netlify Forms pattern:
- Add `data-netlify="true"`
- Add honeypot spam protection
- Set action to `/thank-you`
- Add hidden `form-name` field

**Verification**: Both forms submit to Netlify

### Task 4: Update Config
**File**: `src/config/config.json`
**Action**: Remove obsolete `mailto:` action

Update or remove `contact_form_action` since forms now use Netlify directly.

**Verification**: No broken references to old config value

- **Risk**: Low (Netlify Forms is proven pattern)
