# Phase 3 Plan 2: Dedicated Quote Page & Navigation Integration

## Objective

Create a dedicated `/free-quote` landing page optimized for conversions and integrate it prominently throughout site navigation and CTAs.

## Context

### What Exists
- `CallToAction.astro` partial with embedded quote form
- Navigation configured in `config.json` with "Get Free Quote" button linking to `/appointment`
- City pages with CTA sections using CallToAction partial
- Service pages with various CTA patterns

### What's Missing
- No dedicated `/free-quote` page (SEO-optimized landing page)
- Navigation points to `/appointment` instead of dedicated quote page
- No consistent quote CTA across all pages

## Tasks

### Task 1: Create Dedicated Quote Page
**File**: `src/pages/free-quote.astro` (create)
**Action**: Build SEO-optimized quote landing page

Page structure:
1. Hero section with form prominently displayed
2. Trust signals (25+ years, EPA Safer Choice, etc.)
3. Service area list with city links
4. Testimonial snippet
5. Why choose us benefits

SEO elements:
- Title: "Get a Free Quote | Brimley's White Glove Chem-Dry"
- Meta: "Request your free carpet cleaning quote in Phoenix, Mesa, Gilbert, and surrounding areas. Fast response, no obligation. Call (480) 649-3663."
- H1: "Get Your Free Carpet Cleaning Quote"
- Schema: WebPage with potentialAction for quote request

**Verification**: Page ranks for "carpet cleaning quote phoenix"

### Task 2: Update Navigation
**File**: `src/config/config.json`
**Action**: Point CTA button to `/free-quote`

Change:
```json
"nav_button": {
  "link": "/free-quote",  // was /appointment
  "label": "Get Free Quote"
}
```

**Verification**: Header button links to new page

### Task 3: Add Quote Links to City Pages
**Files**: All 7 city pages in `src/pages/`
**Action**: Ensure CTA sections link to `/free-quote`

Verify each city page's CTA section:
- Primary button: Link to `/free-quote`
- Secondary action: Phone number
- Consistent messaging across all cities

**Verification**: All city CTAs point to quote page

### Task 4: Update Footer Quote Link
**File**: `src/layouts/partials/Footer.astro`
**Action**: Add/verify quote link in footer

Ensure footer includes:
- Prominent "Get Free Quote" link
- Links to `/free-quote` page

**Verification**: Footer quote link works

## Scope

- **Files to create**: 1 (free-quote.astro)
- **Files to modify**: 2-3 (config.json, Footer.astro, potentially city pages)
- **Estimated duration**: 20-25 min
- **Dependencies**: Plan 03-01 (forms must work first)
- **Risk**: Low

## Success Criteria

- [ ] `/free-quote` page created with form and trust signals

- [ ] All city page CTAs verified

- [ ] Page has proper meta tags and schema
- [ ] Mobile-responsive layout
