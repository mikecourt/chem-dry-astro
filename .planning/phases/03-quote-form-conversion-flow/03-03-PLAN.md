Add tracking data attributes to key conversion points:

**Forms:**
```html

```

**CTA buttons:**
```html
<button ... data-track="cta-click" data-track-action="submit-quote">

<a href="/free-quote" ... data-track="cta-click" data-track-action="navigate-quote">
```

**Hero section CTAs:**
```html
<a href="tel:..." data-track="phone-click" data-track-location="hero-[city]">
<a href="/free-quote" data-track="cta-click" data-track-location="hero-[city]">
```

Tracking attribute convention:
- `data-track` = event type (phone-click, cta-click, form-submit)
- `data-track-location` = page section (header, footer, hero-mesa, cta-section)
- `data-track-action` = specific action (submit-quote, navigate-quote, call-now)

**What to avoid:** Don't add JavaScript event listeners yet — data attributes only. GTM will read these in Phase 7.

Document the tracking implementation for GTM setup in Phase 7:

```markdown
# Conversion Tracking Setup

## Overview
This document describes the tracking data attributes implemented on the website
for Google Tag Manager (GTM) integration.

## Trackable Events

### Phone Clicks
- **Attribute**: `data-track="phone-click"`
- **Locations**: header, footer, hero sections, CTA sections, thank-you page
- **GTM Trigger**: Click - All Elements, Filter: [data-track="phone-click"]

### Form Submissions
- **Attribute**: `data-track="quote-form"`
- **Locations**: CallToAction partial, contact page, appointment page
- **GTM Trigger**: Form Submission or Custom Event (form_submission_success)

### CTA Clicks
- **Attribute**: `data-track="cta-click"`
- **Locations**: Navigation, hero sections, content CTAs
- **GTM Trigger**: Click - All Elements, Filter: [data-track="cta-click"]

## Data Layer Events

### form_submission_success
Fired on /thank-you page after successful form submission:
\`\`\`javascript
{
  event: 'form_submission_success',
  form_name: 'quote_request',
  conversion_type: 'lead'
}
\`\`\`

## Conversion Goals

| Goal | Trigger | Value |
|------|---------|-------|
| Quote Form Submission | form_submission_success event | Primary |
| Phone Click | phone-click attribute | Secondary |
| CTA Engagement | cta-click attribute | Micro |

## Implementation Notes
- Data attributes are passive — no JavaScript overhead
- GTM reads attributes via CSS selector triggers
- All tracking happens client-side after GTM is loaded
- Phone number format: (480) 649-3663
```
