# Phase 3 Plan 3: Phone CTA Optimization & Conversion Tracking

## Objective

Optimize phone number CTAs for click-to-call conversions and prepare tracking infrastructure for measuring lead generation effectiveness.

- Phone links scattered across pages with various styling
- GTM container ID in config (disabled)
- No consistent phone CTA pattern

### What's Missing
- Consistent phone link styling and prominence

## Tasks

### Task 1: Audit Phone Link Consistency
**Files**: All pages
**Action**: Document current phone link implementations

Check each page type:
- Header: Is phone number visible on mobile?
- Hero sections: Phone prominence
- CTA sections: Phone as secondary action
- Footer: Phone in contact info

Create consistency report for fixes.

**Verification**: Complete audit documented

### Task 2: Standardize Phone Links
**Files**: Various (based on audit)
**Action**: Apply consistent phone link pattern

Standard pattern:
```html
<a
  href="tel:4806493663"
  class="phone-link text-xl font-bold text-primary hover:text-primary-dark"
  data-track="phone-click"
>
  (480) 649-3663
</a>
```

Ensure:
- All phone numbers are clickable links
- Consistent styling across pages
- Mobile-friendly tap targets (min 44px)

**Verification**: All phone links follow standard pattern

### Task 3: Add Tracking Data Attributes
**Files**: Forms and phone links
**Action**: Add tracking hooks for GTM

Add data attributes for future GTM integration:
```html
<!-- Forms -->
<form data-track="quote-form-submit" ...>

<!-- Phone links -->
<a data-track="phone-click" href="tel:...">

<!-- CTA buttons -->
<a data-track="cta-click" data-cta-location="hero" ...>
```

**Verification**: Data attributes present in HTML output

### Task 4: Create Tracking Documentation
**File**: `docs/TRACKING-SETUP.md` (create)
**Action**: Document tracking implementation for GTM setup

Include:
- List of all trackable events
- Data attribute conventions
- GTM tag recommendations
- Conversion goals to configure

**Verification**: Documentation complete and accurate

### Task 5: Verify Mobile Click-to-Call
**Action**: Test phone links on mobile viewport

Using Puppeteer or manual testing:
- Verify phone links are easily tappable
- Check tap target sizes
- Confirm `tel:` links work correctly
- Test on multiple page types

**Verification**: Phone links work on mobile
