<objective>
Achieve production-ready performance targets: PageSpeed 90+ mobile, 95+ desktop.

Purpose: Performance directly impacts SEO rankings and user experience. Google's Core Web Vitals are ranking factors, and slow load times increase bounce rates for local service searches.
Output: All pages meeting PageSpeed targets with documented optimizations applied.
</objective>

<context>
@.planning/PROJECT.md
@.planning/ROADMAP.md
@.planning/STATE.md

**Target metrics:**
- PageSpeed Mobile: 90+
- PageSpeed Desktop: 95+
- Largest Contentful Paint (LCP): < 2.5s
- First Input Delay (FID): < 100ms
- Cumulative Layout Shift (CLS): < 0.1

**Key areas to audit:**
- Image optimization (WebP, sizing, lazy loading)
- JavaScript/CSS bundle size
- Font loading strategy
- Render-blocking resources
- Server response time (TTFB)

**Pages to test (prioritize high-traffic):**
1. Homepage (/)
2. Phoenix city page (/phoenix) - template for all city pages
3. Services page (/services)
4. Contact page (/contact)
</context>
